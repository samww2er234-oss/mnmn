# اقرأني أولاً — شنو المطلوب منك بالضبط (خطوات مرتبة)

عندك 3 مجلدات/ملفات:

1. **backend** → هذا الي "ترفعه للسيرفر" حتى ياخذ لك رابط.
2. **admin_app** → تفتحه بـ Android Studio (تطبيق الإدارة).
3. **customer_app** → تفتحه بـ Android Studio (تطبيق الزبائن).

## الترتيب الصحيح للتنفيذ

### الخطوة 1: رفع السيرفر (backend)
اقرأ `backend/README.md` بالتفصيل — بيمشيك خطوة خطوة لرفعه مجانًا على Render.com والحصول على رابط شكله:
`https://your-app-name.onrender.com`

### الخطوة 2: ربط الرابط بالتطبيقين
بعد ما تحصل على الرابط، افتح هذا الملف بكل تطبيق وغيّر فيه:
- `admin_app/lib/config/api_config.dart`
- `customer_app/lib/config/api_config.dart`

غيّر السطر:
```dart
static const String baseUrl = "https://CHANGE_ME.onrender.com";
```
لرابطك الحقيقي.

### الخطوة 3: فتح كل تطبيق بـ Android Studio
اقرأ `admin_app/README.md` و `customer_app/README.md` — فيهم أمر واحد أساسي لازم تسويه أول مرة بكل مجلد قبل فتحه بالاستديو:
```
flutter create .
flutter pub get
```
هذا الأمر يضيف الملفات التقنية الخاصة بأندرويد وآيفون (مجلدات android/ و ios/) تلقائيًا حول الكود الجاهز.

## عن آيفون وأندرويد سوا
اخترت Flutter، فنفس الكود (بدون أي تغيير) يشتغل على الاثنين:
- أندرويد: تبنيه وتجربه مباشرة من Android Studio على أي جهاز/محاكي.
- آيفون: يحتاج جهاز Mac مع برنامج Xcode لبناء نسخة آيفون فقط (هذا شرط تضعه شركة Apple نفسها على كل المطورين بالعالم، مو نقص بالكود اللي عطيتك ياه).

## شنو جاهز 100% الحين
- تسجيل الدخول (أدمن + زبون)، تصفح المنتجات والتصنيفات، السلة، إتمام الطلب، تتبع حالة الطلب، إدارة المنتجات/الطلبات/الزبائن/الكوبونات من لوحة الأدمن، لوحة إحصائيات.

## شنو يحتاج منك خطوة إضافية (مفاتيح API خاصة فيك)
هذي أشياء ما أقدر أفعّلها بدون حساباتك الشخصية، لكن الكود بالسيرفر جاهز لاستقبالها:
- **الدفع بالبطاقة**: تحتاج تفتح حساب ببوابة دفع (مثل PayTabs أو Stripe) وتعطيني/تحط مفاتيحها.
- **الخرائط وتتبع المندوب اللحظي**: تحتاج مفتاح Google Maps API.
- **الإشعارات الفورية (Push Notifications)**: تحتاج مشروع Firebase.
- **رفع الصور** (صور المنتجات والبانرات): تحتاج حساب تخزين ملفات مثل Cloudinary أو AWS S3.

إذا جبت لي أي من هالمفاتيح لاحقًا أقدر أربطها بنفس الكود مباشرة.
